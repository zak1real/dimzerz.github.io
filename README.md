# Dimzerz — сайт-портфолио

Статичный сайт (HTML + CSS + JS без сборки), перенесённый со страницы Tilda.

## Структура

- `index.html` — разметка: меню, обложка с фоновым видео, проекты, плейлист, сетап, донат, подвал.
- `style.css` — стили и адаптив (≤960px — бургер-меню, ≤640px — мобильная версия).
- `script.js` — меню, кнопка «наверх», видео и плейлист, донат.
- `images/` — фото сетапа (`vx1000.jpg`, `vx1000-fisheye.jpg`) и картинка-заглушка обложки (`photo-1.jpg`).
- `movie/` — фоновое видео обложки.
- `CNAME` — домен сайта для GitHub Pages (`dimzerz.ru`). Не удаляйте: без него сайт перестанет открываться по домену.

## Как добавить контент

- **Видео в плейлист** — добавьте объект в массив `videos` в `script.js` (`id` — код из ссылки `youtube.com/watch?v=<id>`).
- **Блок «Сетап»** (`#setup`) — заголовок сверху, под ним карточки `.setup__card` (фото + название) в ряд. Чтобы добавить или заменить карточку, положите фото в `images/` (имя латиницей, маленькими буквами, без пробелов и `+`) и скопируйте/поправьте `<figure class="setup__card">` в `.setup__cards`. Описание под заголовком сейчас закомментировано в `index.html`. Большие фото лучше уменьшить до ~1200px по ширине: `ffmpeg -i in.jpg -vf "scale=1200:-2" -q:v 3 out.jpg`.
- **Фоновое видео обложки** — локальный файл `movie/hero.mp4` (17,9 МБ, сжат из исходника командой `ffmpeg -i 333.mp4 -an -c:v libx264 -preset slow -crf 30 -pix_fmt yuv420p -movflags +faststart hero.mp4`), играет по кругу без звука. Чтобы заменить, положите новый mp4 (H.264) в `movie/` и поменяйте `src` у `<source>` внутри `#hero-video` в `index.html`. Пока видео грузится, показывается `images/photo-1.jpg` (атрибут `poster`). Лучше держать файл до 10–20 МБ: он грузится каждому посетителю, а через веб-интерфейс GitHub нельзя загрузить файл больше 25 МБ.
- **Донат** — настраивается в объекте `DONATE` в `script.js`: `hint` — подсказка над кнопками, `links` — кнопки `{ label, url }` (сейчас СБП через Ozon Банк и DonationAlerts). Чтобы добавить способ, допишите ещё одну кнопку в `links`. Кнопки с пустым `url` не показываются; если не осталось ни одной — вместо них серая надпись «Скоро подключим». Блок `#donate` стоит под сетапом, на него ведёт пункт меню.
- **Соцсети** — ссылки и SVG-иконки в `.socials` в шапке `index.html`. Иконки брендов удобно брать с simpleicons.org.
- **Отдельное видео в разметке** — `<div class="video-frame" data-video-id="<id>" data-video-title="Название"></div>`, превью и плеер подставит `script.js`.

## Как работают видео

Ролики в блоке проектов и в плейлисте — встраивания YouTube. Сначала показывается превью с кнопкой Play, плеер грузится только по клику (страница открывается быстрее).

- **Через сервер (`http://` / `https://`, в том числе GitHub Pages)** — видео играет прямо на странице.
- **Двойным кликом по `index.html` (`file://`)** — YouTube такие встраивания не проигрывает (ошибка 153), поэтому по клику ролик открывается на YouTube в новой вкладке.

Фоновое видео обложки — локальный файл, оно работает в обоих режимах.

## Запуск

Чтобы видео играли на странице, запустите локальный сервер: Live Server в VS Code или `npx serve .` в папке сайта.
